# FPGA High-Frequency Trading Projects

## Overview

This repository documents a series of 11 FPGA projects designed to develop proficiency in low-latency hardware systems used in high-frequency trading (HFT).

Projects are implemented using the **Digilent Arty A7-35T FPGA development board** and **AMD Vivado Design Suite**.

The objective is to progressively develop and verify FPGA-based components relevant to high-performance financial trading infrastructure, with an emphasis on minimizing latency and understanding hardware-level data processing.

## Hardware & Development Tools

* **FPGA Board:** Digilent Arty A7-35T
* **FPGA Family:** AMD Artix-7
* **Development Environment:** AMD Vivado Design Suite
* **Verification:** Simulation and on-board hardware testing
